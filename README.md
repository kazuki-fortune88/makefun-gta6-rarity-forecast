Rarity Forecast — forecasts, for each of GTA VI's 55 PS5 trophies, five quantiles of its Exophase earn rate one week after launch, from the trophy history in each case file. Python 3.13, standard library only.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output python3 main.py
```
